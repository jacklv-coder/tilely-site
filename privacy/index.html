PRIVACY POLICY

隐私政策

Tilely 是一款本地优先的时间计划、活动计时与复盘应用。我们尽量减少数据处理，不使用广告、跨 App 追踪或第三方分析。

生效日期：2026 年 8 月 31 日

数据处理 问题反馈 导出 图片与相机 共同空间 通知 保存与删除 儿童隐私 联系

数据处理

你的活动、计划、计时记录、目标和设置首先保存在 Tilely 的本地 App 沙盒中。设备登录 iCloud 且系统允许时，支持的数据可通过 Apple CloudKit 同步到你自己的 iCloud 私有数据库。

Tilely 不会自动把这些私人内容发送给开发者，也不会把这些内容用于广告、画像或出售。当前版本不使用第三方广告 SDK，不进行跨应用追踪，也不使用第三方分析 SDK。

详细记录中的私人文字可随个人记录进入你的 iCloud 私有数据库；图片文件当前默认只保存在本地。根据系统设置，本地内容也可能被包含在 Apple 管理的设备备份中，开发者无法访问该备份。

问题反馈

只有当你在“我的—数据与隐私—问题反馈”中主动点击提交时，Tilely 才会发送你填写的问题或建议，以及 App 版本、Build、iOS 版本、设备类别和语言区域。联系方式为选填，不填写仍可提交。

诊断信息默认不发送；只有在你主动开启选项时才会附上经过脱敏的 iCloud 运行日志。日志不记录计划标题、成员姓名、记录正文、照片、邀请链接或 Apple 账户标识。

反馈由 Cloudflare Worker 加密转发到开发者的私有 GitHub Issues 仓库，仅用于客户支持、回复和改进 Tilely。Cloudflare 与 GitHub 会按各自政策处理必要的网络日志和托管数据；这些数据不用于广告、跨 App 追踪或画像。

数据导出

你可以在“我的—数据与隐私”中主动生成完整 JSON 数据、CSV 记录表和详细记录媒体目录。文件先在设备临时目录生成，随后由 iOS 系统分享页交给你选择的目标。

Tilely 不会自动上传或接收这些导出文件。文件离开 Tilely 后，由你选择的应用或服务按照其隐私政策处理。

图片与相机

从照片中添加图片时，Tilely 使用 Apple 提供的系统照片选择器，不读取你没有选择的照片。只有当你主动点击“拍照”或“扫一扫加入”时，Tilely 才会请求相机权限。

扫码画面仅用于在设备上识别共同空间邀请链接，不会保存为照片。导入图片会生成压缩后的本地副本，并移除原图片中可能包含的位置等元数据。你可以随时从详细记录中移除图片。

共同空间

共同空间是可选功能。只有在你主动创建或接受 Apple 的 iCloud 分享邀请后，Tilely 才会通过 CloudKit 共享成员显示名称、共同计划、活动分类快照、接受或调整状态，以及开始和完成等必要进度事件。

共同空间不会自动分享你的完整时间线、个人目标、暂停原因、私人文字或图片。空间发起人可以停止共享，成员也可以离开。Apple 对 iCloud 和 CloudKit 的处理受 Apple 隐私政策约束。

发起人可以展示邀请二维码或复制邀请链接。任何获得该二维码或链接、并登录 iCloud 的人都可能加入对应空间，因此请只分享给信任的人。Tilely 不会把邀请链接写入诊断日志。

通知

只有在你主动开启提醒、开始休息倒计时或使用共同空间后，Tilely 才会使用系统通知能力。通知用于持续记录、倒计时结束提醒和接收 iCloud 数据变更，不会展示广告内容。

你可以在 App 内关闭常规提醒，也可以随时在 iOS 系统设置中调整通知权限。

保存与删除

本地数据会保存在设备中，直到你删除单条记录、在“我的—数据与隐私”中选择“清除全部数据”，或从设备卸载 Tilely。

删除单条记录会同时删除其文字和本地图片。选择“清除全部数据”时，Tilely 会先停止或退出当前共同空间，再删除本机数据并将删除同步到你的私有 iCloud 数据。此操作不会替其他成员删除其个人记录。

用户主动提交的反馈会在处理问题和改进产品所需期间保存在开发者的私有支持系统中。如需删除，请通过支持页面联系开发者并提供 App 返回的反馈编号。

清除或卸载前，建议先使用 App 内的数据导出功能保存重要内容。当前版本的本地图片不会通过 CloudKit 自动恢复。

儿童隐私

Tilely 是通用效率工具，不要求创建开发者账号，也不会主动收集儿童个人信息。家长或监护人可以根据实际情况陪同未成年人使用。

共同空间定位为共同计划协作，不提供位置追踪、屏幕监控、成员排名或强制控制。

政策变更

如果未来加入开发者账号、第三方分析或其他会改变数据处理方式的功能，我们会在功能上线前更新本政策和 App Store 隐私信息，并在必要时征得你的同意。

联系与支持

如果你对本政策或 Tilely 的数据处理有疑问，可以通过支持页面联系我们。推荐使用 App 内的私密反馈入口；如使用公开 GitHub 页面，请不要附上计划标题、成员姓名、邀请链接、Apple 账户信息或其他私人内容。
